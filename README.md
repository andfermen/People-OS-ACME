# People OS · Acme

Sistema para que **una sola persona** gestione el 360º de RRHH de una compañía con ayuda de la IA y la automatización. Es una prueba técnica sobre **Acme**, una fintech cripto regulada y ficticia.

**Proceso central:** el mapa de skills y cobertura de funciones. Calcula qué funciones quedan descubiertas si una persona se va (semáforo verde/ámbar/rojo), descubre las *key people* y propone acciones con IA, como formar a alguien, moverlo o contratar. People decide y el sistema vuelve a calcular.
